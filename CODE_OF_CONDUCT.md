# Code of Conduct

## Our commitment

In the interest of fostering an open and professional community, contributors,
maintainers, and participants are expected to make participation in this
project a respectful experience for everyone.

## Expected behavior

Examples of behavior that contributes to a healthy environment include:

- being respectful in discussions and reviews
- giving constructive technical feedback
- assuming good intent while still being clear and direct
- focusing on the problem, not the person
- being open to correction and iteration

## Unacceptable behavior

Examples of unacceptable behavior include:

- harassment, insults, or personal attacks
- discriminatory language or behavior
- trolling, deliberate provocation, or bad-faith participation
- publishing private information without permission
- repeated disruptive behavior in issues, discussions, or pull requests

## Enforcement responsibilities

Project maintainers are responsible for clarifying and enforcing this code of
conduct. They may remove, edit, or reject comments, commits, issues, or pull
requests that are not aligned with this document.

## Scope

This code of conduct applies within project spaces, including:

- issues
- pull requests
- discussions
- review comments

## Reporting

If you experience or witness unacceptable behavior, report it to the project
maintainers through the repository communication channels.

Reports should include enough context for review. Maintainers will handle them
as promptly and fairly as possible.
